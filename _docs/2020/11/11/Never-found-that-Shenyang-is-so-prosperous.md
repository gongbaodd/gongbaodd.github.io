# 从未发现沈阳有这么繁华

发现随心飞从兰州出发能直达沈阳，直接买了票，一来能在沈阳休息一阵子，见一见朋友，二来可以看看完全重建好的辽博。

![](https://res.cloudinary.com/dmq8ipket/image/upload/v1762815269/IMG_20201110_105552_aiaomi.jpg)

![](https://res.cloudinary.com/dmq8ipket/image/upload/v1762815267/IMG_20201110_105518_dtwrsi.jpg)

![](https://res.cloudinary.com/dmq8ipket/image/upload/v1762815270/IMG_20201110_120624_hb5dup.jpg)

下了飞机，一如既往的没有地铁，只能大巴到市内，到了市府广场，才发现短短 5 年沈阳发生了很大变化，高楼大厦也多出很多。据朋友说，中街过去半年都在装修，这次我看到中街颇有一点小春熙路的感觉。

![](https://res.cloudinary.com/dmq8ipket/image/upload/v1762815294/Screenshot_2025-11-10_235138_izwqg8.png)

回到工大的老校区，现在已经是一片工地，只留下一个综合楼。没想到学校门口的六毛串吧还依然生意兴隆。

![](https://res.cloudinary.com/dmq8ipket/image/upload/v1762815267/IMG_20201109_125217_udb8xf.jpg)

在沈阳住了几天 lazyBee 青旅，这家青旅的体验异常的好，每天都有诸如英语角，看电影的活动。附近是沈阳的彩电塔夜市，能吃吃炸串鸡架什么的。安利一个烤冷面卷臭豆腐，很有趣的吃法。
