# 路过包头博物馆

从鄂尔多斯到包头，就像是从辽阔的草原 🌾 回到城市街景 🏙️。  
包头是一个**广场特别多的城市**，传说成吉思汗在这里挖出一棵树根，大呼「鹿角」，蒙语音译成「包头」，因此这座城市也被称作**鹿城** 🦌。  

![](https://res.cloudinary.com/dmq8ipket/image/upload/v1757660574/IMG_20200920_115337_bj96yw.jpg)

![](https://res.cloudinary.com/dmq8ipket/image/upload/v1757660580/IMG_20200920_122023_wfrsex.jpg)

包头博物馆基本上可以看作是**内蒙古博物馆的缩小版** 📚。  
这次正好遇到一个关于**印章的特展**，非常有意思 ✨。其中重点展出了**景教的印章**——景教是唐朝时期的基督教分支，马可波罗游记中也有提及，但后来在中国逐渐失传。  

展品中有一种特别的印章：**十字架纽扣** ✝️。它既可以作为装饰佩戴，也能取下来当印章使用，设计相当巧妙。
