# 在绵阳，只记住了一座巍峨的越王楼 🏯

因为要从绵阳飞回大连 ✈️，所以在这里暂住了两天。  
同事推荐我去逛一逛**马家巷**——绵阳本地的小吃街 🍢。  

![](https://res.cloudinary.com/dmq8ipket/image/upload/v1757663120/IMG_20200929_131859_u7fyfr.jpg)

马家巷和成都的小吃街很像，各种麻辣风味应有尽有 🌶️。  
只不过现在自打「盲盒」火了之后，成都连吃小吃也能抽盲盒 🤯。  
相比之下，我还是觉得在广汉吃到的那顿成都小吃更合我口味 ❤️。  

此外，还去了**绵阳市博物馆** 🏛️，它位于城郊的**富乐山**旁。  
说起富乐山，还是刘备给起的名字。当年他路过此地，说这里百姓安居乐业、生活富足快乐，于是命名为「富乐」 👑。  

据说全国现存 19 座汉代摇钱树，绵阳就占了其中的 **5 座**，可谓底蕴深厚。
