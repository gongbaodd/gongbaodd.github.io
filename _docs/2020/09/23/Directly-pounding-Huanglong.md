# 直捣黄龙 🏔️🐉

这趟旅程从虹桥机场出发前往成都 ✈️，是我 2020 年第一趟旅行的最后一站。  
行程相对轻松，基本是跟团游九寨沟，顺便把阿坝周边也逛了一圈 🚌。  

![](https://res.cloudinary.com/dmq8ipket/image/upload/v1757661276/IMG_20200922_180002_rtvhvu.jpg)

过了汶川，再走几个小时的山路 🛣️ 就能到达**黄龙景区**。  
刚到时天气晴朗 ☀️，远山的景致甚至有点 **优山美地** 的味道 🌲。  
景区对**高原反应**的提醒非常严格，比我去拉萨时还夸张 😅。不过实际走下来感觉还好：上山约 2 小时，下山 1 小时，节奏刚刚好。

山上都是**木质栈道**，和长白山有点类似 🌲。  
走起来很轻松，风景同样壮丽，只是这里没有温泉，只有冰冷清澈的泉水 💧。  
阳光明媚时，山间溪水晶莹剔透，随手一拍都是明信片级别 📸✨。
