# 鄂尔多斯，是打开内蒙古的方式 🐎

老实说，呼和浩特给我的感觉并不像「内蒙古」，毕竟它已经是个大城市 🏙️。  
然而到了鄂尔多斯东胜西站，下火车的一瞬间看到的是碧蓝的天空 ☀️，几朵仿佛触手可及的白云 ☁️，让我心里只有四个字——**心旷神怡**。  

![](https://res.cloudinary.com/dmq8ipket/image/upload/v1757659593/IMG_20200917_133358_hokkdw.jpg)

和本地人聊，他们对鄂尔多斯的大规模旅游投资话题都讳莫如深 🤐。比如特意把主要行政区划从东胜搬到新区，但我个人感觉：  
起码在**绿化**上，东胜甩了周边城市好几条街 🌳🌸。从火车站到东胜区中心一路鲜花绿树，让人惊讶这是快要入冬的内蒙。  

![](https://res.cloudinary.com/dmq8ipket/image/upload/v1757659601/IMG_20200920_114257_jvfhaj.jpg)

这次来东胜的重点就是——**骑马体验** 🐴✨。  
在美团上搜到一家「豪士骑马俱乐部」，可以去草原野骑。预约好行程，第二天打车直奔马场 🚕。  

![](https://res.cloudinary.com/dmq8ipket/image/upload/v1757659905/IMG_20200918_102825_ozh8vp.jpg)

这次算是真正意义上的骑马：**没有人拉缰绳**，完全靠自己与马的默契与较劲 ⚔️。  
一开始给我的是一匹烈马 🐎，以我的气势根本压不住它，只有主人甩鞭它才愿意动一下。  

![](https://res.cloudinary.com/dmq8ipket/image/upload/v1757659593/IMG_20200918_105926_nch5gb.jpg)

后来换了一匹蒙古马 🐴。虽然个头不大，却特别能跑。松开缰绳就直接狂奔 ⚡，把我颠得差点飞起来。  
幸好双脚猛蹬、缰绳一拉，才不至于被甩下去。  

![](https://res.cloudinary.com/dmq8ipket/image/upload/v1757659578/IMG_20200918_200337_lg5d1m.jpg)

说真的，那小马硬生生把我「八块腹肌」都颠出来了 💪😂。  

![](https://res.cloudinary.com/dmq8ipket/image/upload/v1757659856/IMG_20200917_215313_ojs36m.jpg)

除了骑马，东胜还有**鄂尔多斯青铜馆**，坐高铁还能去看看**鄂尔多斯博物馆** 🏛️。  
不过这次行程有限，这两个地方只能留到下次啦 ✨。
