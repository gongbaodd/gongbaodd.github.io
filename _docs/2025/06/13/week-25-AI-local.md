# Week 25: AI Locally on Browser

This week I focused on two main things: **Langchain** 🧠 and **Hugging Face transformer.js** 🛠️.  
I learnt how a **multi-modal agent** works 🎯 and how to run models directly in the browser 🌐.

A model can be quite big—anywhere from **10 MB to 2 GB** 📦—so downloading it in a webpage isn’t very user-friendly.  
The [Background Fetch API](https://developer.mozilla.org/en-US/docs/Web/API/Background_Fetch_API) ⏳ is a good solution, but it’s only supported in Chrome and Edge.  
I think providing a **download link** ⬇️ for users to fetch the model themselves, and then verifying the file’s hash 🔍, is also a good complement.
