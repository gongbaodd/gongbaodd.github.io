# Week 26: BabylonJS graphical development, Godot CI and TallinnJS

## BabylonJS Graphical Development

This week I tried Babylon Editor and Babylon Toolkit for a graphical development environment. I found Babylon Editor is more easier to use.

## Godot CI

I was asked to attend a GameJam in China. My team wanted to use godot to make a [landlord simulator](https://github.com/gongbaodd/landlord-simulator). I used [chickensoft-games/setup-godot](https://github.com/chickensoft-games/setup-godot) to setup github action for this game. It supports godot v4+. It is much easier than Unity. [ChickenSoft](https://chickensoft.games/) provides tons of godot toolkit that is nice to try.

## TallinnJS

I attended [TallinnJS](https://tallinnjs.org/) this week. There are two lectures, one for telegram mini app, the other is CSS for responsive design. Loud shout to [Kateryna's blog](https://www.kateryna.codes/talks). And [Utopia](https://utopia.fyi/) a website to test responsive design.

## RapidAPI

I was doing a research for a project, which probably needs a scrapper. I found [RapidAPI](https://rapidapi.com/). The free version allows 2k calls a month. It is enough for me, but I am not sure about the project.
