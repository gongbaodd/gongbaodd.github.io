# Moon Rider

I’ve been playing the open-source VR rhythm game [Moon Rider](https://moonrider.xyz/).  
Today I peeked into its source code and discovered that its song maps actually come from [BeatSaver](https://beatsaver.com/).

This means that with BeatSaver’s huge collection of custom maps, it’s possible to create all kinds of rhythm games—VR or otherwise.
