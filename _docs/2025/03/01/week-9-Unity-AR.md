# Week 9: Unity AR

This week is the end of Unity pathway course. Finally, I finished the last two AR courses. Marker and plane. Marker is to show the 3D object on a graphic image. Plane is to show the 3D object on a plane surface. I tried them with my old Mix2s. It rendered not so acceptable but you still can make some projects. For example, the 3D object cannot follow the marker in every frame. You can feel a little lag. The plane tutorial mentioned stencil shader in the portal. It is harder to learn and since it didn't mention a lot I will return to it later.

Also, the tutorial mentioned visual scripting, it was written in 2022. Back then non-code was a popular idea. But now, it seems that the LLM made a huge effect on the industry. I think the visual scripting will be less popular in a while.
