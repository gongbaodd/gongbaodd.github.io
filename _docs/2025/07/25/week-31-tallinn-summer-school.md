# Week 31: Tallinn Summer School

As I mentioned before, I got a **free chance** to attend Tallinn Summer School! I chose the class **"Experimental Interaction Design"**.  

In this course, I’m working on a **wrist-worn hearing aid** that **notifies the user of emergencies via vibration**. 🚨  

Next week, I plan to use **Edge Impulse** to train a model that can detect **ambulance sirens** — pretty excited to see how it turns out! 😄
