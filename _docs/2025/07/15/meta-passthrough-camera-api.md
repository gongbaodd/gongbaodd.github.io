# 🥽 Meta Passthrough Camera API

I’ve been experimenting with **Meta’s Passthrough Camera API** — check out my attempt [here](https://www.linkedin.com/posts/jian-gong-27762aa8_xr-ai-unity-activity-7350859290649260032-w7Ve?utm_source=social_share_send&utm_medium=member_desktop_web&rcm=ACoAABbfrvsBTcTEUXNxHWRnwteYn_q03d2U-nw) 👀.  

The code is available [here](https://github.com/oculus-samples/Unity-PassthroughCameraApiSamples.git). It uses [Unity Sentis](https://unity.com/products/sentis) to run a **YOLOv8 model** for real-time object detection.  

The API also works with **Meta’s Spatial SDK**. For example, [Meta Spatial Scanner](https://github.com/meta-quest/Meta-Spatial-SDK-Samples/tree/main/Showcases/meta_spatial_scanner) uses **ML Kit** for object detection, and you can hook it up to an **AWS server running a LLaMA model** for more advanced vision-based interactions.  

It’s exciting to see how XR, ML, and real-world passthrough can blend together — the possibilities are huge! 🚀
