# Week 21: 3DGS

Finally, I can talk about 3DGS. Last time I mentioned it was in [2024](../../../2024/07/07/week-27-guassian-splatting). Actually, During these years, I never stopped studying it.

Right now, there are two phone apps can be used to scan environments to 3DGS. [Luma 3D Capture](https://apps.apple.com/us/app/luma-3d-capture/id1615849914) and [Scaniverse](https://apps.apple.com/us/app/scaniverse-3d-scanner/id1541433223), they both easy to use and support to export PLY files.

To edit the PLY file, [MeshLab](https://apps.microsoft.com/detail/9n4tl5dxc6c0?launch=true&mode=full&hl=en-us&gl=ee&ocid=bingwebsearch) is needed. The UI is easy to understand.

You can edit in Blender, however, I did not manage to export the file successfully. The following tutorial can be used to import PLY file in Blender:

- [Procedural 3d scan points cloud to mesh in Geometry nodes - Blender tutorial ENG](https://youtu.be/t3ouR9qEm7M?si=6uM4lfZBaqes7BN4)
- [Blender - Import and render a pointcloud](https://youtu.be/zrxj3n18sG4?si=L0wYGPzQ3A3DUfUy)

Next week, I will import the PLY file and make an XR game.
