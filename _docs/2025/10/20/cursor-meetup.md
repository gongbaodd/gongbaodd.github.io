# Cursor Meetup 💻☕

After [the Cursor Hackathon](/travel/2025/09/28/cursor-estonia), I got invited to this cozy meetup — and of course, I couldn’t miss it! 😄  

![](https://res.cloudinary.com/dmq8ipket/image/upload/v1761038783/IMG_8480_ib2edj.jpg)

The event took place at [Kiosk No3](https://www.kioskkohvik.ee/), a lovely little spot perfect for tech talks and good coffee. ☕✨  

![](https://res.cloudinary.com/dmq8ipket/image/upload/v1761038782/IMG_8484_sf8as8.jpg)

During the session, we discussed some cool new Cursor features — like the new `plan mode` and `browser use`. 🧠  
The `browser use` especially stood out — it feels like a great integration testing tool for developers. 🔍  

![](https://res.cloudinary.com/dmq8ipket/image/upload/v1761038784/IMG_8485_vnxgyz.jpg)

One of the talks shared an awesome approach on how to [vibe coding big projects](https://github.com/eslinko/cursor-rules). 💡  
She uses AI to summarize each folder and stores the markdown inside — saving tokens *and* keeping context tidy. Genius idea! 🤖📂  

![](https://res.cloudinary.com/dmq8ipket/image/upload/v1761038785/IMG_8489_mjabb2.jpg)

Overall, it was a super inspiring night — good talks, smart people, and an even better community. 🚀💬
