# Week 35: 🐐 Goat Counter

Never thought this would happen — I was at the gym 🏋️‍♂️ when I got a notification: my Cloudflare quota was maxed out… all because of the little PV counter I built [earlier](/fe/2025/08/18/pv). 😅  

## Goat Counter

After a bit of thinking 🤔, I figured it’s smarter to use a SaaS instead of reinventing the wheel. That’s when I stumbled upon [Goat Counter](https://www.goatcounter.com/) 🐐✨.  

It offers:  
- 📊 A clean, simple dashboard  
- 📡 A beacon API (no cookies needed!)  
- 🔌 APIs to display PVs directly on my site  

And the best part? It’s **unlimited & free**, with the option to self-host if you want. 🚀
