# 深博海昏侯特展


![poster](https://res.cloudinary.com/dmq8ipket/image/upload/v1781594457/IMG_20190615_142002_gqdagd.jpg)

简直就是江西省储备金展，因为海昏侯墓被鄱阳湖淹了，所以各种书简只能密封保存不能见人，所以在深圳展出的只有金子，晃瞎了我的狗眼。

![money](https://res.cloudinary.com/dmq8ipket/image/upload/v1781594457/IMG_20190615_153426_pwqwhf.jpg)

话说深圳地位真厉害，之前海昏侯只在江西省博，首都博物馆，菏泽博物馆（海昏侯老家）展出过。
