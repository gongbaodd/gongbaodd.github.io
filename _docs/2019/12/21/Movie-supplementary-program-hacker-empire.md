# 电影补档计划：黑客帝国 💊🕶️

![Matrix](https://m.media-amazon.com/images/M/MV5BNzM4OTkzMjcxOF5BMl5BanBnXkFtZTgwMTkxMjI1MTI@._V1_FMjpg_UX1920_.jpg)

男主是个普通程序员💻。一天，他收到一条神秘信息📩——原来自己一直被所谓“母体”控制着。可惜这条消息被系统监控，他很快被抓捕⚡。虽然有人帮忙，他还是被强制植入一个机械虫🪲。

醒来的他以为只是噩梦😱，但很快又收到了女主的消息📲。女主找到了他，帮他拔掉了虫子。男主终于相信女主找到了她的 boss👩‍💼。boss 说：“你们其实一直在未来，只是被蒙蔽了。”  
然后给了男主两颗药丸：🔴红色——看清现实，🔵蓝色——回到虚拟世界。男主毫不犹豫，吃了红色药丸。

当他醒来，发现自己在一个“蛋壳”里🥚，全身插满管子，周围都是包着人的蛋👀。在 boss 的帮助下，他成功逃离了孵化器🏃‍♂️。原来，人类在和机器的战争中失败，机器发现人类体内有巨大能量⚡，于是用人类当电池，把他们困在虚拟世界里，而男主是被选中的救世主✊。

回到虚拟世界后，小队找到了先知🔮，却被告知男主其实不是救世主🤯。突然警察抓捕，小队四散逃窜，boss 被擒。现实中，boss 的手下反水💥，用虚拟世界的身份做交易。反叛者在现实中杀人，对应的虚拟人物也倒下💀。最终反叛者被击毙，只留下男主在虚拟世界救 boss。

男主被机器人击毙⚔️，但女主在现实世界吻了他💋，男主在虚拟世界复活🌟。现在，他能随意操控虚拟世界🕹️，成为真正的救世主，救出了 boss 🙌。
