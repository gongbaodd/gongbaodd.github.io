# 💍 看看哪个小可爱结婚了 🎉

中秋节🌕刚接到前产品刘老板的电话📞，哥们儿要结婚了💒，让我去合肥当伴郎🤵。各种流程套路走完，终于到酒店吃饭，结果我们和服务员撞衫了👔😂。

说到刘老板，其实他的专业是影视相关🎬，所以在做产品的时候，与其他产品不同的地方在于——他很乐意主动去和开发、测试沟通🤝，而不是像很多产品经理那样显得高傲🙄。

还有个趣事：去哪儿用的IM工具是自己开发的 **QTalk** 💬，可以设置自动回复。我当时的自动回复是「然后呢？🤔」，他的则是「不好意思我刚好不在🙈」。结果有一天，这俩自动回复居然互相聊起来，差点把IM服务挤爆了🔥🤣。
