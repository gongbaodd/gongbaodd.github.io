# Tools for Pixel Art

## Kenny Shape

![Kenny Shape](https://res.cloudinary.com/dmq8ipket/image/upload/v1793377521/ohfLnF_gf6gc2.png)

Kenny just released its Voxel Art maker -- [Kenny Shape](https://kenney.itch.io/kenney-shape). This time, I can use aseprite to make pixel art then use it to make it lowpoly 3D. 

Years ago, I tried [MagicaVoxel](/tech/2018/08/31/magicavoxel/).  I found it super relieving to use it. But you need a little 3D mind to build it.

Last year, while I was studying [the 3D scan class](/tech/2025/10/17/week-43-hunyuan-3d/) at school. I also tried to use hunyuan model to make a lowpoly grandpa.

![grandpa](https://res.cloudinary.com/dmq8ipket/image/upload/v1793378156/Screenshot_20261030_183510_dncvhi.png)

These are great tools for making an XR app.

## Universal LPC Spritesheet Character Generator

![sprite sheet](https://res.cloudinary.com/dmq8ipket/image/upload/v1793378472/download_e6up4k.png)

Two years ago, when I was doing [the 2D graphic class](/fe/2024/12/16/2d-graphics/). I always wanted to make a character movement sprite sheet tool.

[Universal LPC Spritesheet Character Generator](https://liberatedpixelcup.github.io/Universal-LPC-Spritesheet-Character-Generator/) is one implementation. You have to mention the author in your product. Anyway, the implementation is so completed, strong suggest to try.
