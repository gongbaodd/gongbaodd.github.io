# Week 40: Digit Conference 2026

This year's [Digit Conference](https://digit.dev) is hold at kammivabrik in Tartu. From my understanding, it is an event majorly for python developers.
In the morning at 5 a.m. I got up and took off to catch the bus at Tallinn Bus station, and I left Tartu Bus station at 8 p.m.

The conference includes two sections, software engineering and data & machine-learning. They all includes workshops to attend. 

![CONFERENCE](https://res.cloudinary.com/dmq8ipket/image/upload/v1791641131/IMG_3981_w9usik.jpg)

Before I go, I made a plan to attend these topics.

- Synthetic Counterfactuals for Text Classification: Detecting AI-Written Job Postings in the Wild
- What We Can Learn from Exemplary Python Documentation
- MLVC: Building the World’s Most Efficient Video Codec
- Building Kubernetes-Native Python Applications
- Own Your LLM: Lessons from Building a Local AI Agent
- You Are the Harness. Until You Build One
- Causal Agentic Data Science

The speeches are in the same hall, so one of it has to wear headphones.

![head phones](https://res.cloudinary.com/dmq8ipket/image/upload/v1791641131/IMG_3983_k4dguo.jpg)

## What We Can Learn from Exemplary Python Documentation

This is a workshop by [Christian Heitzmann](https://www.linkedin.com/in/christian-heitzmann), aims to use [Sphinx](https://www.sphinx-doc.org/en/master/index.html) to generate code docs into html. The document structure uses [reStructuredText](https://www.sphinx-doc.org/en/master/usage/restructuredtext/basics.html) as markup text structure.

![](https://res.cloudinary.com/dmq8ipket/image/upload/v1791641131/IMG_3991_xzgilz.jpg)

The workshop also introduced [google style docstring](https://google.github.io/styleguide/pyguide.html#38-comments-and-docstrings). [kroki](https://kroki.io/examples.html) is used as diagram tool, however, I went to another speech in half of the workshop.

## MLVC: Building the World’s Most Efficient Video Codec

This is a speech by [Evgenii Indenbom](https://www.linkedin.com/in/eindenbom/). This [codec](https://github.com/microsoft/MLVC) is used for microsoft teams, which is useing numberical regression to make predict frames to insert inside of actual frames. The [paper](https://arxiv.org/abs/2606.28027) is also a worth to read.

![MLVC](https://res.cloudinary.com/dmq8ipket/image/upload/v1791641130/IMG_3998_zx70pr.jpg)

## Building Kubernetes-Native Python Applications

This is a workshop by [Lauri Võsandi](www.linkedin.com/in/laurivosandi/). The project is to use MCP to develop new features on [lolcatz](https://github.com/codemowers/lolcatz).

## Own Your LLM: Lessons from Building a Local AI Agent

This is a speech by [Heili Aavola](https://www.linkedin.com/in/heili-aavola/), who was using local LLM agent (Hermes agent) with 2 Nvidia GPUs.

![](https://res.cloudinary.com/dmq8ipket/image/upload/v1791641130/IMG_4017_aovmew.jpg)

Although, I do not think local LLMs can solve all the security issues(should be harness). I really like the [cheatsheet](https://res.cloudinary.com/dmq8ipket/image/upload/v1791647363/Own-Your-LLM-cheat-sheet_ywocjn.pdf). It compared several runtimes, vLLM & tensorfold, several local runable models and some easy configs for spark platform.

## You Are the Harness. Until You Build One

This is a speech by [Kirill Linnik](https://www.linkedin.com/in/kirill-linnik). The topic is about multi-agent. He introduced [OpenAI Symphony](https://openai.com/index/open-source-codex-orchestration-symphony/) which can be used for agents orchestration. Simply speaking, the agents will do the issue fixing and validation work instead of human.

He also mentioned [DevClub](https://devclub.ee/), a monthly meetup event in Estonia.

## Causal Agentic Data Science

This is the last one, the speech is by [Carlos Trujillo](https://www.linkedin.com/in/cetagostini). I thought it would about some data science. But it was more like the workflow. He mentioned [paseo](https://paseo.sh). I have never used it befor. I intend to use it.
