# The HuggingFace Agents Course

This is a fundamental [agent course from huggingface](https://huggingface.co/learn/agents-course/en/unit0/introduction).
It can be regard as a supplement of [the AI course](/series/aisoft-course/) I learnt this June. As the agent part of that course was too shallow.

While I am traveling in Finland. I made the course into a [pdf](https://drive.google.com/file/d/15ycRi6D-ez6P0YEP9_Mzws0iBQp1eXJK/view?usp=sharing) to read.

For me the introduction part is too easy. The framework part is quite interesting. It compared smolagents, LlamaIndex and LangGraph. And how to evaluate them.

The bonus units are also a good to read.

The [quiz 1](https://huggingface.co/learn/agents-course/en/unit1/quiz1), [quiz 2](https://huggingface.co/learn/agents-course/en/unit1/quiz2) can be used for checking if you understand AI Agents enough.

The [tool](https://huggingface.co/learn/agents-course/en/unit1/tools) part, there is a very good implementation of a tool use interface.

The [smolagents](https://huggingface.co/learn/agents-course/en/unit1/tutorial) implementation is a very simple one. Then use the smolagent to build [code agent](https://huggingface.co/learn/agents-course/en/unit2/smolagents/code_agents). [RAG Systems](https://huggingface.co/learn/agents-course/en/unit2/smolagents/retrieval_agents), although I like the [RAG unit](https://huggingface.co/learn/agents-course/en/unit3/agentic-rag/introduction) more. [Multi-Agents](https://huggingface.co/learn/agents-course/en/unit2/smolagents/multi_agent_systems) and [Vision Agents](https://huggingface.co/learn/agents-course/en/unit2/smolagents/vision_agents).

The LlamaIndex part, need to know how to call [tooling](https://huggingface.co/learn/agents-course/en/unit2/llama-index/tools). Creating [agents workflow](https://huggingface.co/learn/agents-course/en/unit2/llama-index/workflows).

For langgraph, [create the nodes](https://huggingface.co/learn/agents-course/en/unit2/langgraph/first_graph) is a must to read, and how to [analyse](https://huggingface.co/learn/agents-course/en/unit2/langgraph/document_analysis_agent) it.
