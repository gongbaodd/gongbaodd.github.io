# Google I/O Chrome Updates

## 🤖 Built-in AI & Developer Tools

* **Gemini in Chrome**: Bringing Google's AI capabilities directly into the browser.
* **Built-in AI: Early Preview Program**: Sign up and explore at [goo.gle/chrome-ai-preview](https://goo.gle/chrome-ai-preview).
* **On-Device Intelligence**: Running AI models locally.
* **Prompt API**: Note that there is currently no Chinese language support. 🛑


* **AI-Assisted Tooling**: Enhancing developer workflows with AI.
* **Chrome DevTools for Agents**: Features an MCP server to support multi-agent workflows.
