# G-Helper: Control Tool for ASUS windows

I downgraded my Windows 11 to Windows 10. I still have a lot software that can not run in Linux, but windows 11 is just too slow.

However, as long as I plug in, the fan runs crazily. Even though, it is the balance mode.

Then I found [G-Helper](https://github.com/seerge/g-helper), it can force the laptop into silent mode even it is plugged in.

![screenshot](https://res.cloudinary.com/dmq8ipket/image/upload/v1782288878/split-3_hu_ebea83a8f7467653_f12wx8.webp)

I strongly suggest every ASUS user to try it.
