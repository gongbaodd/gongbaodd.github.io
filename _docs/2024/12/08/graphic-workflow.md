# Graphic Workflow

Recently I have finished a project that needs very high quality of graphics. 

Firstly, draw the concept on Google Slideshow.

Find the fonts from [dafont](https://www.dafont.com/).

Then, use Inkscape to draw vectors. Normally, inkscape's exported svg can be used in krita's vector layer. But some masks and paths may lost. So some image have to be exported as PNGs. Remember the original dpi of the image is 96. But for printing, it should be 300.

Also, I made some AI art. I found a good [tutorial](https://youtu.be/G_D1wsUjcNo?si=B6Lb6gdOHAA9sbVE) to make AI QRcode. Hint that fail a lot, not better than the older [blog](https://stable-diffusion-art.com/qr-code/) using Stable Diffusion Web UI. But antfu's [QRCode generator](https://qrcode.antfu.me/) is very good.

Finally, use Krita to assemble them, using guide lines can help you calculate the size of your artwork. 300 dpi means 300px is 1 inch. An iphone is about 3x6 inches.
