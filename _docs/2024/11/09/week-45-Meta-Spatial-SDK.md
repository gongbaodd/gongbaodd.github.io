# Week 45: Meta Spatial SDK

This week I tried Meta's [Spatial SDK](https://developers.meta.com/horizon/develop/spatial-sdk). It is an Android Studio module that allows you to build XR experience for Meta Quest devices. Currently, there is no support for previewing and compiling time is long. Shorter than Unity build, but still need to wait. But there is a webview that allows you to make a webpage inside the page. I have not test the webXR support yet, but it is a good trend. And I wish there will be a react-native support for that.

I also tried [the Meta XR plugin for Unreal Engine](https://developers.meta.com/horizon/develop/unreal). Unreal Engine is quite heavy for my laptop. And the official document, which tells me to find the plugin in the marketplace, is not helpful. I can't find the plugin in the marketplace. I ended up following [this tutorial](https://dev.epicgames.com/community/learning/tutorials/y4vB/unreal-engine-5-4-x-for-meta-quest-vr) in UE forum. Giving me a godot feeling.

Speaking of godot, Meta has not yet supporting godot. Even though godot received a lot money from Meta. I hope there will be a plugin in the future.
