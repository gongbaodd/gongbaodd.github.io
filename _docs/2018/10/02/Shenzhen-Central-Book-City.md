# 📚 深圳中心书城

人太多了 😅 …不是说十一深圳成空城了么？这就是所谓的“空城”？👀  

![](https://res.cloudinary.com/dmq8ipket/image/upload/v1759305950/IMG_20181002_173222_oiry7k.jpg)

书城位置在市民中心，和博物馆就在附近 🏛️。坐地铁到 **少年宫站** 下车是最近的 🚇。  
里面真的是人挤人 🤯，但依旧有人能安静看书，真佩服这种专注力 ✨。  

书城西面是 **深圳音乐厅 🎶**，东面是 **城市规划馆 🏙️**。可惜整个十一没赶上开放，真是难得一遇。  

书城里第一个区域，西面有个计算机类书摊 💻。规模比南山书城大些，图灵丛书也挺多 📖。不过想看技术书的话，还是上网更方便 🖥️。
