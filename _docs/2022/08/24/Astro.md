# Astro：前端框架的“最终形态”？✨

这几天刷 YouTube 📺，发现大家都在疯狂推荐 **Astro**！  
它可以说是比 React、Vue 更高一维度的框架 🚀。

Astro 的特别之处在于：  
- 可以把目前主流的前端框架作为渲染器生成静态页面 📝  
- 页面中需要交互的部分，还能用「岛屿架构」🌴 单独挂上去  

更有趣的是，同一个项目里还能混用不同框架 🤯！  
和 Next、Gatsby 相比，Astro 给人的感觉就是：更简单、更轻盈，也更贴心 ❤️。
